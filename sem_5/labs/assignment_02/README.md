# Web Development Lab - Assignment 02

## Objective
The objective of this assignment is to style the HTML symposium website (TechNova 2026 for SSN College of Engineering) created in Assignment 01 using ONLY HTML and CSS. The design remains beginner-friendly without the use of Bootstrap, Tailwind, or JavaScript.

## CSS Concepts Used
This project satisfies all mandatory CSS requirements listed in the assignment question:
- **CSS Selectors**: Element, Class, ID, Descendant, Pseudo-class (`:hover`), Pseudo-element (`::before`).
- **Box Model**: Margin, Padding, Border, Border-radius, Box-sizing (`border-box`).
- **Typography**: Font family, size, weight, text alignment, transformation, and letter spacing.
- **Colors & Backgrounds**: Background colors and text colors for theme consistency.
- **Navigation Bar**: Sticky navigation with hover effects and active page highlighting.
- **Layout using Flexbox**: Used for Navigation, Highlights section, Contact layout, and Footer.
- **CSS Grid**: Used to layout the Technical and Non-Technical event cards.
- **Tables**: Styled Schedule and Prize tables with borders, alternate row colors (`nth-child`), hover effects, and header styling.
- **Forms**: Styled the Registration form including labels, inputs, select dropdowns, textareas, and submit/reset buttons with focus effects.
- **Positioning**: Sticky positioning for the navigation menu.
- **Display Property**: Block, inline, and inline-block displays.
- **Responsive Design**: Media queries for Mobile, Tablet, and Desktop optimization.
- **Images**: Responsive sizing, rounded corners, and box-shadow.
- **CSS Effects**: Transition, Transform, Box-shadow, Text-shadow, and Opacity.
- **Footer**: Common styled footer across all pages.

## Pages Included
1. **Home (`index.html`)**: Overview of the symposium, banner, and highlights.
2. **About Symposium (`about.html`)**: Objectives, vision, mission, and why to participate.
3. **Technical Events (`technical.html`)**: Details of Paper Presentation, Web Design, Coding Challenge, and Project Expo.
4. **Non-Technical Events (`nontechnical.html`)**: Details of Photography, Quiz, Treasure Hunt, and Gaming Tournament.
5. **Event Schedule (`schedule.html`)**: Complete event timetable in a tabular format.
6. **Registration (`register.html`)**: Form for participants to submit their details and select events.
7. **Contact Us (`contact.html`)**: Faculty and student coordinator details, address, and college location map.

## How to Run the Project
1. Open the `src` folder.
2. Double-click on `index.html` to open it in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.).
3. Use the navigation bar to browse through all the different pages of the website. No live server or build tools are required as this uses plain HTML and CSS.
