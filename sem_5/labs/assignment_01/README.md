# TechNova 2026 - College Symposium Website

**College:** SSN College of Engineering (Sri Sivasubramaniya Nadar College of Engineering)
**Location:** Kalavakkam, Chennai, Tamil Nadu, India
**Organizing Department:** Department of Computer Science and Engineering

## Objective

To design and develop a multi-page website for a national-level college technical symposium called **TechNova 2026** using only HTML. The website provides information about the event, showcases competitions, displays schedules, and allows students to register online.

---

## Pages Created

| Page | File | Purpose |
|------|------|---------|
| Home | index.html | Welcome page with symposium overview and highlights |
| About | about.html | Detailed information about the event, vision, mission, and benefits |
| Technical Events | technical.html | Lists all technical competitions with rules and prizes |
| Non-Technical Events | nontechnical.html | Lists entertainment events with rules and registration fees |
| Event Schedule | schedule.html | Complete timetable of events for the day |
| Registration | register.html | Online registration form for participants |
| Contact Us | contact.html | Coordinator details, venue address, and social media links |

---

## HTML Tags Used

- `<!DOCTYPE html>` - Document type declaration
- `<html>` - Root element
- `<head>` - Metadata container
- `<title>` - Page title
- `<body>` - Page content container
- `<header>` - Page header section
- `<nav>` - Navigation links
- `<section>` - Page sections
- `<article>` - Individual event articles
- `<footer>` - Page footer
- `<h1>` to `<h4>` - Headings
- `<p>` - Paragraphs
- `<a>` - Hyperlinks / navigation
- `<img>` - Images
- `<ul>` - Unordered list
- `<ol>` - Ordered list
- `<li>` - List items
- `<table>` - Tables for schedule and prize details
- `<tr>` - Table row
- `<th>` - Table header cell
- `<td>` - Table data cell
- `<form>` - Registration form
- `<input>` - Form input fields (text, email, tel, submit, reset)
- `<select>` - Dropdown menu
- `<option>` - Dropdown options
- `<textarea>` - Multi-line text input
- `<label>` - Form field labels
- `<b>` - Bold text
- `<br>` - Line break
- `<hr>` - Horizontal rule
